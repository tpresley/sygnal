# TUI spike: a full-featured terminal app on `sygnal/terminal`

Spike, 2026-10-31, branch `claude/tui-friction-spike-c95421` (base `claude/advanced-integration` at 60cd4b5f).
This is research, not a plan of record. F-numbers are local to this file.

**Short answer.** The terminal target ran the component model fine, but it couldn't host a real TUI. It had no box layout: no columns, no fixed status bar, no scrolling regions. It had no `<select>` interaction beyond ← / →, which the footer didn't mention. It had no `<dialog>`, no caret, and no paste. It left the terminal broken after a crash. All of those were on Sygnal's side, not the app's. They are fixed here in `sygnal/host` and `sygnal/terminal`, each with tests. The app's own problems were isolation mistakes that a browser would have hit the same way. The `sygnal/ui` dialog behavior and the Toaster still don't run in a terminal: they read the global `document` (F13), and their files belong to other sessions, so the change is described below rather than made.

## The app

`examples/tui-tracker`, an issue tracker: `npm --prefix examples/tui-tracker run terminal`.

- a list/detail layout (the issue list beside its detail pane), the list scrolling in its own box, 40 issues;
- a tab set (`sygnal/ui` `tabs`), a disclosure (`disclosure`), keyboard shortcuts (`keymap`: `/ n r j k x d 1 2 3 q`);
- a form with the `form` behavior: a text input, a textarea, checkboxes, a radio group and a native `<select>`, with validation errors and the server's 422 on its field;
- a modal confirm (a native `<dialog>`, `ELEMENT: { showModal }`);
- a fake API with latency behind `makeFetchDriver({ fetch })`: a loading state and a "Syncing…" status;
- a status bar pinned to the last row; `q` quits through the new `TERMINAL` sink.

10 tests (`src/app.test.js`, in `test:examples`): the layout, scrolling, the filter, the dropdown, the modal, the form end to end, the 422, mouse and wheel, quitting, and `runTerminal` on fake TTY streams. It is `sygnal-check --strict` clean.

## Decisions for the maintainer

1. **Mouse off by default** (Bubble Tea and Ink; Textual turns it on). With it on, the terminal's own text selection needs Shift-drag.
2. **Ctrl+D no longer quits**: in a text field it deletes forward (readline, Textual). Ctrl+C and a `TERMINAL` exit quit.
3. **Ctrl+A in a text field goes to the line start** (readline, Textual), not select-all as in a Windows browser; ⌘A still selects all. The keydown goes out first, so an app can take it.
4. **Cell widths in-house** (a 17-range table plus `Intl.Segmenter`) rather than the `string-width` package as a dependency. D209 would allow `string-width`: it is small and framework-neutral. It would track Unicode updates for us, at the cost of three transitive packages.
5. **Console output buffered by default on a TTY** (written after the restore, counted in the footer), as Textual does; Ink writes it above its output instead.
6. **The `sygnal/ui` `document` fix (F13)**: for the session that owns `src/ui/`.
7. **`[tabindex]` Enter activation (F21)**: keep it, or narrow it as recommended.
8. Whether to add `settle()` / `run()` to `createTerminal` (F20) and `suspend` (F22) now or later.

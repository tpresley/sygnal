# Widgets, web components and UI parts

`defineWidget` (third-party widgets: date picker, chart, editor), web components, `sygnal/ui` parts (dialog, popover, tooltip, tabs, menu, select, combobox, toasts), `fromReact` / `fromZag`, drag to reorder (`sortable`), `VirtualCollection`, `browser` sources, `lazy`.

- **Third-party widget** (date picker, chart, editor): `defineWidget({ tag, mount(el, props, dispatch), update, unmount, events, commands })` is a tag: `<DatePicker className="due" value={state.due} />`, `DOM.select('.due').events('pick').detail()` (never `DOM.select(DatePicker)`), `OPEN: { ELEMENT: { open: '.due' } }`; tests `t.widget('.due').dispatch('pick', d)`. A web component is an element: render its tag, select its class (`web-components.md`).
- Dialog, popover, tooltip, tabs, accordion, disclosure, toasts → `sygnal/ui` behaviors + `<Toaster />`; Menu/Select/Combobox → `sygnal/ui/menu|select|combobox` widget tags (events `select` / `value-change`); one React or Zag component → `fromReact` / `fromZag` (`adapters.md`).
- Drag to reorder → `uses = { sort: sortable({ from, item, handle }) }` + a live region for `state.sort.message` (English; a spec's wording: `messages: { drop, cancel, … }`, `(label, position, count) => text`). Long list → `<VirtualCollection className="rows">` is the scroll container: height, `aria-label`, `role` on it, never in your own scrolling `<ul>` (SYG430: fix the height); jump with `ELEMENT { scrollToIndex | scrollToId }`. Visibility/size/media/storage/network → `browser` static + `makeBrowserDriver()` (`browser-sources.md`); `lazy(…, { when: 'visible' })`.
- Table → TanStack in the view; i18n → `.context.t` + `persist` (`recipes/overview.md`).

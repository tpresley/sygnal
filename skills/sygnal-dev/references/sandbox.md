# Sygnal: Sandboxed components (`sygnal/sandbox`, dev preview)

> A topic file of Sygnal's agent context. It assumes the core (`llms.txt`, or the sygnal-dev skill's `SKILL.md`: mental model, component anatomy, canonical forms, wiring rules, testing): read that first. Canonical forms only.

- Untrusted or model-written components (dev preview): `sygnal/sandbox` (`npm install quickjs-emscripten-core @jitl/quickjs-wasmfile-release-sync`) runs one in QuickJS-in-WASM, rendered into the real DOM through an allowlist: `import { Sandboxed } from 'sygnal/sandbox'` + `import kernel from 'sygnal/sandbox/kernel?raw'` (sygnal/vite builds it from the installed packages; else `buildSandboxKernel()` from `sygnal/sandbox/build`), `<Sandboxed className="card" kernel={kernel} source={cjs} emits={{ ANSWER: AnswerSchema }} input={{ bill: state.bill }} />` (`source`: CommonJS, JSX compiled to `__h`/`__frag`; `emits` required: only declared types with schema-valid data arrive, SYG692 otherwise) + `ANSWER: DOM.select('.card').events('emit').detail().filter(e => e.type === 'ANSWER').map(e => e.data)`, `'sandboxerror'` (`{ reason, message }`); `isolation: 'worker'` (default: hostile code, a watchdog) or `'thread'` (model-written code, sync events); the guest has `DOM`, `STATE`, `EVENTS`, `PROPS`, and `HTTP` only via `capabilities.fetch: { allow: [urlPrefix] }`; guide `advanced/sandboxed-components`.

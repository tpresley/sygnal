# Sygnal: Typed API calls (`sygnal/api`, dev preview)

> A topic file of Sygnal's agent context. It assumes the core (`llms.txt`, or the sygnal-dev skill's `SKILL.md`: mental model, component anatomy, canonical forms, wiring rules, testing): read that first. Canonical forms only.

- **Typed API calls** (dev preview, `sygnal/api`): requests built from the server's contract, no URLs or reply types written: `const api = orpcClient(contract, { prefix: '/api' })` (an oRPC contract, served by oRPC's OpenAPIHandler; or `openApiClient<paths>()`, `honoClient<ExtractSchema<typeof app>>()`), then `api.quotes.list({ tag })` is a request (a resource), `api.quotes.add(input, { ok: 'ADDED', error: 'FAILED', invalidates: [api.quotes.list] })` a sink value, a stream endpoint a `connections` entry; actions typed `Output<typeof api.quotes.add>` / `ApiFailure<typeof api.quotes.add>`; tests `t.respond('HTTP', fixture(api.quotes.list, rows), api.quotes.list)`. Function-first (`sygnal({ api: { functions: true, handler: 'server/api.ts' } })`): `src/quotes.server.ts` exports `query(z.object({ tag: z.string() }), async ({ tag }) => …)` / `mutation` / `stream` (input always validated), which components import and call like endpoints (the client build gets stubs only); the server mounts `serverFunctions(import.meta.glob('/src/**/*.server.ts', { eager: true }), { os })` with oRPC. Guide: `node_modules/sygnal/dist/guide/typed-apis.md`

## And what if you just wanted to build a great app?

You're in the right place. Sygnal is a complete reactive framework for everyday development: pure JSX views, automatic state management, TypeScript, routing, forms, accessible UI parts, and Astro and Vike integrations. Use your editor, your agent, or both. AI features are opt-in.

The same architecture that helps an agent reason about your code makes it easier for you to read, test, and maintain. **Intent** describes when something happens. **Model** describes what changes. **View** renders the state. No hooks, selectors, or dispatchers.

**Upgrading from 6.x?** 7.0 changes reducer timing: [Migrating to 7.0](/guide/migrating-to-7/).

### A small component. The whole idea.

A view is a function. Its behavior lives alongside it. Press **Edit** to make this one your own.

```jsx live
function Counter({ state }) {
  return (
    <div>
      <p>Count: {state.count}</p>
      <button className="increment">+1</button>
      <button className="reset">Reset</button>
    </div>
  )
}

Counter.initialState = { count: 0 }

Counter.intent = ({ DOM }) => ({
  INCREMENT: DOM.click('.increment'),
  RESET: DOM.click('.reset'),
})

Counter.model = {
  INCREMENT: (state) => ({ ...state, count: state.count + 1 }),
  RESET: (state) => ({ ...state, count: 0 }),
}
```

# Sygnal: Islands, three.js scenes (`sygnal/three`), 2D canvas editors (`sygnal/canvas`)

> A topic file of Sygnal's agent context. It assumes the core (`llms.txt`, or the sygnal-dev skill's `SKILL.md`: mental model, component anatomy, canonical forms, wiring rules, testing): read that first. Canonical forms only.

## In short
- **Imperative island** (three.js scene, canvas, map with markers as JSX children): `defineWidget({ children: true, mount, sync })`; the children are elements the widget reads in `sync` and draws; it dispatches DOM events on them (raycast / hit test → `click` on `v.elm`), so each child component's intent uses `DOM.click('.cube')`. Per-frame motion is computed in the widget from props, not in state (`islands.md`). A three.js scene: `<Scene>` from `sygnal/three` (`npm install three`): meshes, geometries, materials, lights and cameras as lowercase tags, raycast hits as `click` / `pointerover` on the mesh's element with `event.point`, `animate={{ rotation: (t) => [0, t, 0] }}` for motion, `<Model src="/tree.glb" />` / `<Texture src="/wood.jpg" />` for loaded assets (with `<Suspense>`; a failed load renders `onError`), `capture="xz"` to drag a mesh along the floor (`pointermove` with `event.captured` and `event.delta`), `draggable` for `processDrag`, tests with `sceneOf(el).click(meshEl)` / `.drag(meshEl, [x, y])` under `dom: 'real'` (`renderers/three.md`).

## Details
- Islands (a three.js scene, a canvas, a map: parts as JSX children): `defineWidget({ children: true, mount, sync(instance, childrenVnode, el), focus(instance, child) })`. The tag's children render (by Sygnal, as elements: components, `<Collection>`, intents work) into a visually hidden, accessible container; `sync` reads them (`v.sel`, `v.data.props` / `v.data.attrs`, `v.elm`) and draws them; the widget turns raycasts / hit tests into DOM events on `v.elm` (`el.dispatchEvent(new MouseEvent('click', { bubbles: true }))`), so `DOM.click('.cube')` works in the child's intent. Enter / Space on a focused child (`role`, a name, `tabIndex={0}`) is its click. `tags: ['marker']` stops the pragma treating the widget's tags as SVG. Per-frame values: compute them in the widget's own loop from props, never through state; a `timers` `{ frame: 'ACTION' }` only for state that changes every frame. Guide: `islands.md`. three.js ready-made: `import { Scene } from 'sygnal/three'` (`npm install three`, an optional peer): `<Scene className="viewport" width={640} height={400}><ambientLight /><Collection of={Cube} from="cubes" /></Scene>`, every three.js class lowercased as a tag (`<mesh position={[x, 0, 0]}><boxGeometry args={[1, 1, 1]} /><meshStandardMaterial color="orange" /></mesh>`), raycasts become DOM events with `event.point` (`DOM.click('.cube')`), per-frame motion `animate={{ rotation: (t) => [0, t, 0] }}` (never state), tests in jsdom `sceneOf(el).click(meshEl)`. Loaded assets are tags: `<Model src="/tree.glb" position={[0, 0, 0]} />` (GLTF by default; `loader={OBJLoader}` or a configured loader instance for others; one clone per element) and `<Texture src="/wood.jpg" />` inside a material (attaches as `map`; `attach="normalMap"`), with `<Suspense fallback={…}>` around them (inside the Scene: a 3D fallback; around it: the scene is created once loaded); cached per URL, freed with the last element using it, `Model.preload(src)`; a failed load renders the component's `onError`. Dragging: `capture="xz"` on a mesh captures the pointer from the press to the release (`gotpointercapture`, then every `pointermove` with `event.captured`, `event.point` on the drag plane and `event.delta` from the press, then `lostpointercapture`; a drag clicks nothing; camera controls sit it out); `draggable` sends the HTML drag events, so `processDrag({ draggable: DOM.select('.box'), dropZone: DOM.select('.bin') })` works; tests `sceneOf(el).drag(meshEl, [x, y])`; guide `renderers/three.md`. 2D editors, whiteboards, diagrams (experimental): `import { Canvas, pointer } from 'sygnal/canvas'`; shapes are data in state, one box-based vocabulary (`{ id, type: 'rect' | 'ellipse' | 'text' | 'frame' | 'line' | 'path', x, y, width, height, rotation, fill, stroke, radius, parent }`, an ellipse is its box, not SVG's cx/cy/rx/ry): `<Canvas className="board" camera={state.camera}><shapes className="doc" items={state.shapes} active={draggedIds} />{handles(selectionBox(state.shapes, state.selection), state.camera)}</Canvas>`; one element paints, culls and hit-tests all shapes, a hit is a DOM event with `e.hit` = the id: `DOWN: DOM.select('.board').events('pointerdown').map(pointer)` (plain `{ x, y, hit, part, shift, mod }`, world coordinates); every press is captured (`e.captured`, `e.delta` from the press); pan/zoom built in, the camera a controlled value (`CAMERA: DOM.select('.board').events('camerachange').detail()`); drags go through actions (`gesture.start/move/delta`, `snap`, `resize`, `rotation`, `turn`; `history('shapes')`: `commit(s, next, gesture.before)` = one undo step per gesture, `UNDO: h.undo`; with `sygnal/yjs` `shared()` the same entries become per-user undo). Patch only changed shapes (`shapes.map(s => s.id === id ? { ...s, x } : s)`; rebuilding all is SYG262: every frame repaints; per move, work on the changed shapes only: `positionsOf(shapes, prev)` is an id → index map shared across a drag's arrays, a derived list returns its previous array when its rows didn't change); `follow={{ ids, from }}` only for huge selections; `exportSVG(shapes, ids)`; tests `canvasOf(el).pointer('down', x, y)`; guide `renderers/canvas.md`.

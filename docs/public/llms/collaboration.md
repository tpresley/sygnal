# Sygnal: Collaborative state (`sygnal/yjs`, experimental)

> A topic file of Sygnal's agent context. It assumes the core (`llms.txt`, or the sygnal-dev skill's `SKILL.md`: mental model, component anatomy, canonical forms, wiring rules, testing): read that first. Canonical forms only.

- **Collaborative state** (experimental, `sygnal/yjs`; `npm install yjs y-protocols`, optional peers): several users edit one key of the state at once, merged by a Yjs document. `Board.uses = { board: shared({ presence: 'peers', history: 'history', shape: { title: 'text', items: collection({ text: 'text' }) } }) }` (import `shared`, `collection`, `makeYjsDriver` from `'sygnal/yjs'`); keep `board` in `Board.initialState` (`shared()` adds no slice of its own: `ownsState: false`, so no SYG127). Reducers stay ordinary: each new `state.board` is diffed into the document (`board.LOCAL`, once per flush) and other users' changes arrive as `board.REMOTE` (applied only while there's no unsynced local edit; both hidden in DevTools as built-in). main.js: `run(Board, { SHARED: makeYjsDriver({ doc, provider }) })` with the app's own `Y.Doc` and provider (y-websocket, Hocuspocus, y-webrtc, y-indexeddb); the first value seeds an empty document after the provider's first sync (`seed: 'whenSynced'`, default; `'ifEmpty'` for a local-only doc), else the document wins. Arrays of objects with `id` are id-keyed collections (concurrent add/edit/move/remove merge); declare `'text'` fields for character-level merging and declare empty arrays (`'list'` / `collection()`; else SYG261). Undo per user: `UNDO: { SHARED: { undo: 'board' } }`, `REDO: { SHARED: { redo: 'board' } }`, never `undo({ key: 'board' })` (SYG260: it reverts others' changes); presence `FOCUS: { SHARED: (state, id) => ({ presence: { editing: id } }) }` → `state.peers`; offline `{ SHARED: { connect: false } }`. Tests: `const net = createNetwork(), peer = net.join()` (from `'sygnal/yjs/testing'`), `renderComponent(Board, { drivers: { SHARED: makeYjsDriver({ doc: peer.doc, provider: peer }) } })`, `peer.offline()` / `peer.online()`. Guide: `node_modules/sygnal/dist/guide/collaborative-state.md`

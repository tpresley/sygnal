Connect this chat client to the chat server over WebSockets. The room buttons, the Leave button and the composer already work; nothing talks to the server yet.

- Joining a room (clicking "General" or "Random") opens a WebSocket to `/ws/rooms/<room>` on the page's own host, where `<room>` is `general` or `random` (`ws://` on an `http:` page, `wss://` on `https:`). The client keeps at most one connection open: switching to the other room closes the current connection and opens one for the new room, and "Leave room" closes it. Clicking the room you are already in changes nothing.
- `.connection` shows "Not connected" when you are in no room, "Connecting…" while the first connection to a room is opening, "Online" once it is open, and "Reconnecting…" from the moment a connection drops until a new one is open.
- The server sends each chat message as a JSON text frame like `{ "user": "ana", "text": "hi" }`. Append it to `ul.messages` as an `<li>` reading "ana: hi". The list holds the current room's messages since you joined it: switching rooms or leaving clears it, reconnecting to the same room keeps it.
- Submitting the composer sends `{ "text": "<what was typed>" }` as a JSON text frame and clears the input; blank input sends nothing. The Send button is disabled unless the connection is Online. The server echoes your own messages back like anyone else's, so don't add them to the list yourself.
- A connection drops when it closes without the client closing it, or when it fails to open. Then try again to the same room 1 second later, and keep retrying every second until a connection opens. Switching rooms or leaving cancels a pending retry. A connection the client closed itself never causes a retry or a status change.

This is a small notes app with an editor and a status bar at the bottom. The status bar always says "Ready". Make it reflect what is happening in the editor:

- When the user changes the text, the status bar should say "Unsaved changes".
- When the user clicks Save, it should say "Saved N words", where N is the number of words in the text that was saved (use "1 word" for a single word).

Keep the editor and the status bar as separate components.

The project is TypeScript; `npm run typecheck` must pass.

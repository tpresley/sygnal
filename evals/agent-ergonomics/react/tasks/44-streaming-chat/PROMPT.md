Build the support chat in `src/App.jsx`. The server side exists: `POST /api/chat` is an AI SDK 7 route (`streamText(...).toUIMessageStreamResponse()`). It takes the whole conversation as AI SDK UI messages (`{ "messages": [{ "id", "role": "user" | "assistant", "parts": [{ "type": "text", "text": "…" }] }] }`) and streams the reply back with the UI message stream protocol.

- A form with a text field labelled "Message" and a "Send" submit button. Sending clears the field, shows the message at once, and posts the conversation so far: every earlier message and reply in order, the new message last. A message that is blank (or only spaces) sends nothing. The page never reloads.
- The conversation is an `ol.messages` with one `li` per message, in order, with class `user` or `assistant`, holding the message's text.
- The reply appears in its `li.assistant` while it streams, growing as the text arrives.
- While a reply is on its way (from sending until it has fully arrived), "Send" is disabled and a "Stop" button is shown; at any other time there is no "Stop" button. "Stop" cancels the request: the text received so far stays as the reply, nothing that would still arrive is shown, and "Send" works again.
- If the request fails (an HTTP error, a network error, or an error in the stream), show "Something went wrong." in an element with `role="alert"`, with a "Retry" button. "Retry" removes the alert and sends the same conversation again: the user's message is not repeated, and any part of the failed reply that had arrived is dropped. Sending a new message also removes the alert.

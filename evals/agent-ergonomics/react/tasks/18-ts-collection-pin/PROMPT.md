In this task list app, add a "Pin" button to every task row. Clicking a task's Pin button makes it the pinned task: the line under the "Tasks" heading, which currently says "Nothing pinned", should then say "Pinned: <task title>" (for example "Pinned: Walk the dog"). Only one task can be pinned at a time, so pinning a different task replaces the previous one. Checking tasks off should keep working.

The project is TypeScript; `npm run typecheck` must pass.
